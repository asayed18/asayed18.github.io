# Experience City

A personal website where software engineering experiences are shown as buildings along a foggy road. Scroll to walk; approaching a building reveals a side panel with details.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Edit your content

Edit `src/data/experiences.ts`: add or change entries (id, position 0–1, title, description, period, company, link, tags). Update the header in `src/components/Header.tsx` with your name and links.

## Build

```bash
npm run build
npm run preview
```
